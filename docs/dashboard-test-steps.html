🧪 LLM Tuner — Step-by-Step Testing

How to install, run, and test the app on your Mac (or the VPS)
Dashboard Test Steps GitHub

📋 Choose Your Path

A. Mac (full loop) B. VPS (partial)

Path A (Mac): Full end-to-end — generate, import, train, compare. Requires Apple Silicon.
Path B (VPS): Quick smoke test at http://76.13.122.86:8090 — no install needed.

🖥️ Path A — Mac (Full Loop, ~20 min)

1 Install LLM Tuner

Open Terminal (Applications → Utilities, or Spotlight → "Terminal") and paste:

curl -fsSL https://raw.githubusercontent.com/lecharles/llm-fine-tuner-agent-tester/main/install.sh | bash
What it does: Checks Python 3.12+, downloads the app to ~/.llmtuner, prompts for API keys (Anthropic/OpenAI — optional, press Enter to skip), creates the llmtuner command.

Troubleshooting:

  • If Python is missing: install from python.org
  • If ~/.local/bin is not on PATH: add export PATH="$HOME/.local/bin:$PATH" to ~/.zshrc, restart Terminal

2 Start the App

llmtuner up

This starts the server on http://localhost:8000 and opens your browser. You should see the login screen.

If the browser doesn't open: manually go to http://localhost:8000

3 Create an Account

  1. Click "Sign up" on the login page
  2. Enter email + password + display name
  3. Click "Sign up" → you're logged in

Expect: You land on the dashboard. Your account owns everything you create below.

4 Generate Q&A Pairs

  1. Click Datasets in the sidebar → New dataset
  2. Name: test-demo
  3. Prompt: "10 Q&A pairs about our refund policy: 30-day window, receipt required."
  4. Iters: 10 (smoke budget)
  5. Click Generate

Expect: 10 pairs appear with source badges (local Ollama if no API keys). Takes ~1-2 min.

5 Import from CSV (Optional)

  1. Same dataset → Import from file
  2. Upload a CSV with columns question,answer and 3 rows
  3. Click Import

Expect: The 3 pairs append immediately with csv source badge.

6 Train a Model

  1. Click Train in the sidebar
  2. Pick dataset: test-demo
  3. Iters: 10 (smoke) or 200-400 (real tune)
  4. Click Start training

Expect:

  • Status flips to running
  • Live loss curve appears and gains points every few seconds
  • On completion, the model appears under Models as test-demo-qlora
If training fails: the run card shows a red error box with the exception text + log tail. Never silent.

7 Compare Models

  1. Click Compare in the sidebar
  2. Column A: base model (e.g., llama3.2:1b)
  3. Column B: test-demo-qlora (your fine-tuned model)
  4. Optional: add OpenAI/Anthropic/Ollama columns from the dropdowns
  5. Ask: "Can I return this without a receipt after 40 days?"

Expect:

  • Tuned column cites 30-day + receipt policy
  • Base model is generic
  • Every answer ≤150 words
  • Failed columns show their reason in-column (not silent)

8 Done! ✅

You've completed the full loop: generate → import → train → compare.

To stop the server: Ctrl+C in Terminal, or close the Terminal window.

🌐 Path B — VPS (Quick Smoke Test, ~5 min)

No install needed. Just open your browser.

1 Open the VPS Instance

Go to http://76.13.122.86:8090

Expect: Login page. Hard-refresh if you see a stale page (Ctrl+Shift+R / Cmd+Shift+R).

2 Create an Account + Generate

  1. Sign up with any email/password
  2. Create a dataset, generate 10 pairs

Expect: Generation falls through to the server's Ollama (local engine), badges visible.

3 Import CSV

Same dataset → Import from file → upload a CSV with question,answer columns.

Expect: Appends fine on the shared instance.

4 Try to Train (Should Refuse)

Click Train, pick the dataset, click Start training.

Expect: 425 "Training runs on the Mac app only" — no doomed run created. The VPS doesn't have Apple Silicon/MLX, so training is blocked by design.

5 Compare

Compare base model vs Ollama column vs any hosted columns (if configured).

Expect: 150-word cap applies, in-column errors persist (not silent).

6 Done! ✅

You've smoke-tested the VPS instance. Training is Mac-only by design.

✅ Pass Criteria Checklist

  • Install completes without errors
  • llmtuner up starts the server and opens the browser
  • Sign up / sign in works
  • Generate produces Q&A pairs (local Ollama fallback if no API keys)
  • Import from CSV appends pairs
  • Train shows live loss curve, completes successfully (Mac only)
  • Compare shows tuned vs base model differences
  • Failed columns show reasons in-column (not silent)
  • VPS training refuses with 425 (Mac-only preflight)

🐛 Troubleshooting

Python missing or too old

Install Python 3.12+ from python.org

~/.local/bin not on PATH

echo 'export PATH="$HOME/.local/bin:$PATH"' >> ~/.zshrc
source ~/.zshrc

Browser doesn't open automatically

Manually go to http://localhost:8000

Training fails silently

This shouldn't happen anymore (H3 hotfix). If it does, check the red error box on the run card. If there's no error box, open a GitHub issue.

VPS login returns 401

Hard-refresh the page (Ctrl+Shift+R / Cmd+Shift+R). The H1 hotfix fixed the Origin header issue.

Need help?

Open a GitHub issue: github.com/lecharles/llm-fine-tuner-agent-tester/issues
