# October 2026 Retro — the commit train, month two

**Window:** 10-01 → 10-31 UTC · **Slices:** S16 close-out through S45 (month close) · **Commits on main in the window:** 31 · **Test count:** 46 → 121 · **CI:** green on every pushed slice

## What went well

- **The streak held.** Carlos's 10-05 rule — at least one commit every calendar day — survived the whole month, including Sat/Sun rows deliberately scoped VPS-safe (docs/tests/polish) so the lane never idles. When days were missed (weekend of 10-23/24, S27/S28), the catch-up runs cleared them oldest-first exactly as designed.
- **Scope discipline paid off.** "Stay inside the Scope column, one focused diff" meant 30 commits that never tripped on each other; the api_agents extraction (S41) could land with a grep CI guard because nothing drive-by-imported it back in.
- **The MAC pattern works as a queue, not an excuse.** 10 Mac-dependent slices shipped as `DONE (Mac verify pending)` with numbered recipes in commit bodies — the lane kept moving and Carlos can verify in any order. (Which also means: see "deferred".)
- **Decision docs beat drifting.** ADR-001 (hybrid, S22) and ADR-002 (in-repo extraction, S40) each unblocked a week of slices; the two platform spikes (S42/S43) stayed desk-research + recipes instead of burning lane time on hardware the lane can't touch.

## What did not

- **Long-lived process drift.** The live `:8090` backend keeps stale modules in memory until it restarts — S41 (api_agents) and S44 (indexes/CSP/throttle) are both "shipped but dark" until a restart. The lane cannot start/stop long-lived processes, so this needs an operator window.
- **Root-owned `deploy/`.** Two slices hit the same wall (S21 relocation, S41 follow-up note). One `sudo chown -R hermes:hermes deploy/` from Carlos closes it.
- **An interrupted lane run.** The 10-31 run died after staging S44's indexes/CSP work but before committing; the 11-01 run found a dirty tree and had to audit a stranger's WIP as if it were its own. Recovery was clean (review → validate → commit), but "commit the moment verification passes" is now a lane hard rule to shrink that window.
- **GitHub API auth degraded at close.** The token in `secrets/github.env` returns 401 for issue comments (git push still works). November lane runs will skip comments until the token is refreshed.
- **Mac verify debt is growing.** 10 pending verifications + 6 stale screenshots + H1/H3 browser checks. Each is individually cheap; as a pile they gate v0.2.0.
